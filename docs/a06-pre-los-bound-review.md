# A06 pre-LOS row-min bound review

The pre-LOS row-min expression is a valid lower bound for the implemented bearing_set_map_v1 objective when its target bundle is complete and is prepared from the same candidate scorer. The proof uses the exact likelihood matrix rather than a Gaussian approximation. For each report row, every complete partial injection either pays that row's clutter cost or matches the row to one visible group. Replacing the selected edge by a minimum over all pre-LOS component representatives and all possible group uncertainties can only reduce that row cost. Dropping unused-group penalties also reduces the objective because the v1 group miss cost is -log(1 - detection_probability), which is positive. The assignment relaxation permits reports to reuse a record and therefore enlarges the feasible set. The baseline remains unchanged. Thus the bound is the baseline plus rowwise minima of clutter and edge floors.

The catalog row floor uses the canonical build_likelihood_costs implementation for every admissible component-maximum uncertainty. This matters because the wrapped Gaussian mixture need not be monotone in sigma. For a known representative, every possible subgroup maximum is a known component uncertainty at least as large as the representative's own uncertainty. For an unknown representative, the exact scorer uses zero when the subgroup has no known uncertainty, or the maximum known member value otherwise. Taking the minimum over these possibilities is conservative. The geometry uncertainty-to-bearing conversion must use degrees(atan2(U, range)), including the zero-range case, and must retain negative log-likelihoods without clamping.

The angular components are computed before line-of-sight filtering. Removing blocked records can split a circular component but cannot merge two components. The pre-LOS grouping may be coarser than the exact scorer when type labels prevent cross-type merging; this only adds possible uncertainty maxima and weakens the floor. The nearest representative and tie rule must still match the exact predictor, which selects minimum (range_m, key) after LOS filtering. Extent does not enter the v1 likelihood.

The coverage certificate establishes known-water observer coverage and known coverage for every target ray supplied to it. It does not establish that the target list is complete. Therefore raw caller-supplied target rows, arbitrary geometry, or a certificate alone cannot justify pruning. The public bound is eligible only when it accepts a factory-minted prepared bundle tied to the exact CandidateScorer, candidate, complete prepared prediction context, measurements, configuration, catalog, map, and target certificate. The extractor must mirror the predictor's nearby-record scan and detect unsupported feature models before range filtering. Any unresolved nearby model, unknown map coverage, invalid-water candidate, unsupported offset, covariance model, common bearing bias, or nonpositive clutter intensity must return unresolved and cause exact scoring or another approved fallback.

The bound is finite-candidate only. It says nothing about candidates omitted by proposal generation and cannot certify a continuous location domain. Its use remains experimental until the caller passes only the verified prepared bundle and preserves exact fallback for every unresolved case.

## Validation

Independent review tests and commands will be recorded here after the adapted implementation is available. No benchmark truth, held-out data, timing, or full search run is part of this audit.

The independent fixture prepares five physical records through the production CandidateScorer path and compares the bound with the exact scorer result and every one of the 32 possible clear/blocked subsets. It independently groups each subset with the canonical circular grouping contract and enumerates all partial one-to-one report/group assignments, including report clutter and unused-group costs, through the independent reference oracle. The fixture checks the circular bridge component, type labels, report-specific uncertainty, known and unknown catalog uncertainty, negative matched costs, and direct edge floors against independently recomputed uncertainty variants. A separate zero-range case checks the atan2(0, 0) limit against the exact scorer. Hand-calculated assignment fixtures verify empty inputs, positive-infinity forbidden edges, all seven tied partial injections for a complete 2 by 2 zero-cost matrix, and the two outcomes with costs 0 and 3 for a one-report one-group example.

The adapted production-preparation, bound, and coverage suites passed 37 tests. Locked all-group dependency synchronization completed. Ruff and ty both passed on the owned audit test. The tests do not invoke proposal generation, use benchmark truth, access held-out data, or measure runtime.

The review permits experimental pruning only for a finite candidate set whose caller passes the factory-minted PreparedPreLOSTargets for the same CandidateScorer, measurements, and configuration, and exact-scores any unresolved bundle. The row-min proof does not certify candidates omitted by proposal generation or any continuous region. The component is not wired to the production search caller in the reviewed state, so production pruning remains unapproved until that caller-level binding and exact fallback are independently checked.
