# Candidate coverage certificate

The coverage certificate provides a conservative proof that a candidate observer and its complete set of in-range target coordinates lie inside known map coverage. It verifies the observer is known water and that the convex hull of observer and targets is covered by the known coverage geometry without intersecting explicit unknown geometry. A failed or incomplete proof returns no certificate. The proof does not replace line-of-sight checks against land.

The public preparation API is prepare_candidate_coverage_context(map_v2, *, target_crs=None). It parses, validates, normalizes, and prepares the map snapshot once. For projected metre input, omit target_crs. For geographic input, pass the same projected metre CRS used by scoring, such as target_crs="EPSG:32618". Preparation applies one explicit pyproj transform with always_xy=True, matching VectorMap.from_map_v2, then records the canonical source CRS, canonical target CRS, map metadata, and normalized geometry digests in the prepared identity. Candidate and target XY coordinates are already expected in that target CRS. A context for a different projection has a different identity.

For each candidate, call certify_candidate_coverage(context, candidate_xy_m, target_map_xy). The target input must contain every exact in-range, offset-corrected target as (record_key, target_xy_m) with unique keys. The resulting immutable certificate binds the candidate, sorted key-coordinate pairs, and prepared map identity. Consumers check certificate.matches_map(context) and certificate.covers(candidate_xy_m, target_map_xy); either mismatch fails closed. Map parsing, reprojection, WKB hashing, and prepared geometry construction happen once per context rather than per candidate.

Focused tests cover projected-map certificates, observer water and shore handling, land rejection, explicit unknown gaps, coverage holes, overconservative convex envelopes, empty target sets, and geographic-to-EPSG:32618 parity with VectorMap.from_map_v2. The geographic tests compare water, land, unknown, hole, and uncovered point classifications and reject a certificate prepared in a different projection.

Validation completed with uv run ruff format, uv run ruff check, uv run ty check, and uv run pytest -q tests/accuracy/test_a11_coverage_certificate.py. The focused suite passed 12 tests. Combined related vector and water-map checks passed 34 tests.
