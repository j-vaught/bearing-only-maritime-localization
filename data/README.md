# Shared East Coast inputs

The folder contains two independent object catalogs, one map, observer locations, and source/checksum information. The source catalogs retain every record from the previous combined catalog with unchanged IDs, coordinates and metadata.

| File | Contents |
|---|---|
| `objects-ais.json.gz` | 2,268 AIS vessel records. |
| `objects-chart-aids.json.gz` | 64,400 chart-aid records. These are not necessarily distinct physical objects. |
| `map.json.gz` | Land polygons and explicit known/unknown coverage. |
| `observer_locations.csv` | 24 simulator/evaluator locations with current map status. |
| `objects.manifest.json` | Counts, compressed/raw checksums and deterministic combination metadata. |
| `map.manifest.json` | Map checksums, coordinate system, coverage and provenance. |
| `map-source-validation.json` | Original geometry validation evidence. |
| `sources.json` | AIS and chart source descriptions, retired CSV hashes, and observer-table checksum. |

The loader expands the chosen archives into ignored JSON files in this folder. For `both`, it creates `objects-combined.json` from AIS followed by chart aids; this generated combination is not another committed dataset. It verifies the generated file against the manifest.

Choose `CATALOG_MODE = "ais"`, `"chart_aids"`, or `"both"` in an example. Search bounds live in `examples/_common.py`. Bearings are generated by the simulator when an example runs. The simulator always uses both physical catalogs, so choosing a smaller search catalog leaves other visible objects as unmatched detections.

The map uses EPSG:4326 and searches use EPSG:32618. Approximately 23.7 percent of the declared region has unknown coverage, which is not inferred as water. Chart sources have unresolved physical identities and mixed epochs; their original metadata remain in the object records.

Observer coordinates are truth for simulation and evaluation. Search never receives them. The locations retain their original coordinates. Fifteen are water and nine are land on the map identified in the table. The simulator rechecks geometry and rejects invalid positions.

The duplicate source CSVs and saved demonstration bearings have been removed. Historical source tables remain in Git history; source descriptions and checksums are retained in `sources.json`.
