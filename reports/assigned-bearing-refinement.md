**Assigned bearing refinement proposal**

The new module bearing_localization.search.assigned_bearing_refinement implements a bounded local proposal for an already scored Hypothesis. Its public entry point is refine_assigned_bearing(scorer, hypothesis), with propose_assigned_bearing_refinement provided as a descriptive alias. The result is a typed AssignedBearingRefinementResult containing the original hypothesis, proposed projected pose, exact canonical hypothesis only after strict objective improvement, numerical status, solver counts, residual counts, assignment count, and canonical evaluation count. The improving status is named improved so it cannot be confused with a downstream fix decision.

The proposal freezes the input report-to-representative assignments while fitting signed wrapped bearing residuals with scipy.optimize.least_squares. Each residual uses the report-specific sigma combined in quadrature with the representative catalog uncertainty and applies the configured sigma floor. The projected pose is transformed to longitude and latitude, then each representative feature bearing is computed with WGS84 geodesic inverse geometry. Calibrated visible-feature true-east and true-north offsets are propagated with WGS84 forward geometry. Type labels do not enter the geometric residual.

The solve uses at most 100 function evaluations and an initial local rectangle extending 1000 m from the seed in each projected axis, clipped to the configured global bounds. The final candidate is always passed to CandidateScorer.evaluate, which recomputes water status, map coverage, range, line of sight, angular grouping, uncertainty, type likelihood, and the complete one-to-one assignment. A non-scored, failed, max-evaluation, equal, or worse proposal returns no exact replacement, so the caller retains the original hypothesis. The result is a local proposal and provides no fix acceptance or completeness claim.

The implementation rejects nonzero common-bearing calibration and every measurement covariance mode explicitly because the current independent residual fit does not model covariance. It validates the complete canonical seed hypothesis before fitting, then rejects missing bounds, invalid or insufficient assignments, stale scores, out-of-domain seeds, unsupported map or catalog outcomes, and solver failures. The module has no truth, evaluator, support, or known-position inputs.

The focused suite in tests/accuracy/test_assigned_bearing_refinement.py passes twenty-one tests together with the existing A20 refinement tests. These tests exercise noisy recovery, unequal sigmas, final assignment changes, worse-proposal retention, stale hypotheses, forced maximum evaluation, solver exceptions, invalid and insufficient assignments, unsupported calibration and covariance, unsupported catalog metadata, final land and unknown-coverage rejection, clipped local bounds, missing global bounds, and UTM projected coordinates with true-north behavior.
