# Distinct-marker pruning and local rejection proofs

The optimized resident search now rejects a cell when its positive marker reports cannot be assigned to distinct possible chart objects. The old checks required an individual explanation for every bearing and enough objects nearby, but could reuse the same object in several individual checks. The new incidence graph requires all reports to have a simultaneous injective explanation. A cell with enough nearby objects can therefore fail when several reports depend on the same smaller subset of those objects.

Every graph edge represents a possible physical explanation anywhere inside the observer cell. The edge includes the existing conservative range, whole-cell true-bearing, object position and feature bounds. Unknown object types remain possible chart markers. Known vessels are excluded because the trusted positive reports are chart aids. Unknown sight lines remain possible, while the existing certified land barriers can exclude an object only when blockage holds for the complete cell and supported target position. No missing or undetected object creates a penalty.

The physical observation model matters. The simulator emits a distinct physical group's representative bearing with bounded sensor error. A reported aid must therefore have a physical object that can explain its measured bearing. The positive reports are distinct detections from one view, rather than repeated reports of one aid across time. A nominal group's angular extent can establish possible support, but does not prove that its representative can move anywhere inside that extent. Terminal positive certification now requires a selected exact match inside the physical bearing tolerance, with numerical boundary cases left unresolved.

Graph construction and augmenting-path matching run on the graphics processing unit. Missing proof certificates, unsupported position bounds, exhausted capacity, insufficient workspace, and numerical or tree failures retain the candidate. No bounded workspace silently discards graph columns. Identity uncertainty disables distinct-object rejection unless the required identity certificate is present. The existing individual-object absence proof remains available when it does not depend on distinct identities.

Terminal scoring reuses the same graph at a zero-area cell centered on the evaluated terminal rectangle. A certified physical impossibility proof takes precedence over nominal grouped matching, even when unrelated predicted objects produce numerical-boundary or unknown-visibility diagnostics. A nominal grouped matching failure cannot by itself reject an optimized candidate when the conservative physical graph still permits an explanation. Original nominal flags remain visible in the output. Positive acceptance still requires the conservative nominal flags and exact matched groups; the independent graph localizes safe rejection without dismissing uncertainty that could affect sensor grouping.

The new rejection proof requires complete chart-object scope, rather than complete shoreline coverage throughout a surrounding square. Separately, a positive supported position requires known observer water and certified selected sight lines, rather than known shoreline everywhere around the sensor. Unknown geometry needed by the actual explanation still prevents unsupported certainty. Position and identity certificates for chart proofs are restricted to objects that could be chart markers; uncertain known vessels cannot disable a chart-only proof.

The output retains the existing terminal status codes. The additional marker_rejection_reason field records zero when no certified physical rejection exists, two when a report has no possible object, three when there are too few possible distinct objects, and four when the incidence graph has no injective assignment despite passing the individual and total-count checks. A rejected center remains a center result; it does not reject its entire surrounding terminal rectangle. Whole-cell pruning uses the complete rectangle instead.

These changes operate on the saved prepared arrays and canonical object view. They do not change source geometry, preparation identity, object canonicalization, the saved cache, original search artifacts, or the frozen Charleston estimate. The legacy pruning path remains available as a comparator with distinct_markers=False. Verification uses focused synthetic unit cases and independent review. A new regional or coast-wide search requires user approval.
