# Search repair checkpoint figure

This interim figure groups four independent evidence slices dated 2026-10-26. The matched baseline panel reproduces identical local and coast position errors from main and integration using matching measurement and catalog fingerprints. The line-of-sight panel compares scalar and batched crop execution on the same 909 rays and unchanged status vector; its batch timing includes crop creation. The wedge panel contrasts a budget-limited 87-pair prefix with complete coverage of 333,340 source pairs, and labels the 7.452 s measurement as voting-only. The final panel shows the unresolved 48 s pairwise attempt, which exhausted its candidate budget, returned an ambiguous decision, and remained hundreds of kilometres from the known point.

The source JSON preserves hashes for all three source reports, data inputs, the LOS ray fixture and result vector, and the two implementation files used by the exact search case. Report files and the figure source were checked against the source-worktree snapshot before plotting. No new search or timing run was performed for this figure. The panels have separate workloads and units, so the timings must not be interpreted as one end-to-end comparison. The V1 branch comparison establishes identical errors on those two fixed inputs; the isolated LOS measurement establishes only fixture-level component timing; the wedge duration excludes scoring and map evaluation; and the A43 search remains a failed, unresolved case rather than an accuracy estimate.

The 250 m follow-up case is pending and is not represented. This checkpoint is not a release accuracy figure and provides no held-out accuracy or field-validation result.

Typst compiled the source to a one-page PDF and a 130 ppi PNG. The full rendered page was visually inspected after an initial two-column layout clipped chart axes and captions; the final stacked layout keeps all four panels, values, units, and source references inside the page. Extracted PDF text was checked for the expected captions, exact values, and limiting scope language. The PNG is 1740 x 1535 pixels; the PDF page measures 963.78 x 850.39 points.
