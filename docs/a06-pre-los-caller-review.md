# A06 review of the experimental pre-LOS profile caller

The reviewed caller is the isolated diagnostic in tools/profile_pre_los_bound.py. It does not wire pruning into production search. It re-scores the saved incumbent with the current scorer and rejects the run if the saved score differs. Each candidate remains in the original order, and each receives either an exact status or a proposed-prune disposition. A proposed prune requires a water point, a supported prepared-target bundle bound to the same scorer and inputs, a coverage certificate, a finite supported bound, and a strict score gap above the current exact incumbent.

Unsupported preparation and bound results use the canonical exact scorer. The incumbent can only improve as exact fallbacks are scored. The strict margin now covers both the configured score tolerance and the final isclose tie rule, including negative scores where relative tolerance scales with magnitude. Every proposed prune is exact-scored again after the pass. The caller rejects an unscoreable prune, a bound above its exact score, or a pruned exact score in the best-score tie band.

The command validates the selected candidate IDs, positions, order, static input hashes, selection hash, configuration hash, score statuses, and scores against both frozen artifacts before considering screening. It also computes a direct exact score for every selected candidate and compares those results with the saved artifacts. Completion requires matching direct and screened best scores and tie IDs, with every candidate accounted for exactly once. The default output state is prepared_no_screening; screened_complete is written only after the guarded pass and post-pass checks succeed. A nonblocking canonical benchmark lock is acquired before input processing, so the diagnostic cannot overlap a lock holder.

Independent A06 tests exercise ordered complete accounting, seed validation, exact fallback for unsupported bounds, negative-score relative-tolerance boundaries, and post-pass exact validation for proposed omissions. These tests use small synthetic fixtures and do not execute a screening profile or access held-out truth.

The caller review passes for one diagnostic screening run after the benchmark lock is released and the coordinator authorizes execution. This review applies only to the score-only profile harness. It does not establish production pruning correctness beyond the bound and preparation preconditions, and it does not authorize changing the frozen sample, scorer, configuration, or inputs.
