# Validation support extension, 2026-10-26

This version preserves the anchor-corrected validation plan and adds only the deterministic placement extension required by the frozen support rule. The initial plan is archived as anchor-corrected-2026-10-26; the extended trial table retains every original row with identical metadata. The extension adds placements 026–050 for validation port-002, for the two physical realizations, three range settings, and both report-type settings.

The original 25-placement validation population had 92 supported nominal rows out of 200 in each 1 km type condition, below the required 100. The existing deterministic extension selected port-002 and added 300 rows. After preparation, all six condition counts passed the support minimum: 136/250 in each 1 km condition, 178/250 in each 5 km condition, and 181/250 in each 10 km condition. The frozen eligibility manifest records 2,340 validation rows, including 1,500 nominal rows, 990 supported nominal rows, and no unresolved rows. These are preparation eligibility counts, not localization accuracy results.

eligibility-validation.json contains the A42 frozen eligibility evidence. preparation-summary.json binds the extended plan and eligibility hashes to the 300 successful extension outputs and the 60 failed first attempts. Those failures were retained as distinct attempt records when the corrected plan-aware preparation adapter retried them successfully. Raw prepared input directories remain in the ignored .agent-work output tree and are not part of this commit.
