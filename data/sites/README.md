# Port and observer coordinates

These CSV files retain historical manual test locations. Identifiers belong to each file and are not interchangeable.

`b1-b5.csv` contains the five original Chesapeake positions. `east-coast-ports-b1-b10.csv` contains ten East Coast approach positions. `east-coast-major-ports-top150-2024.csv` contains 24 Atlantic port-area anchors based on the U.S. Army Corps of Engineers 2024 leading-port table.

The older observer positions were selected using a coarse 500 m mask. Validate any position against the current vector map before simulating there; a stored point is not evidence of navigable water under the current geometry.

Source port lists are available from [USACE port statistics](https://www.iwr.usace.army.mil/Missions/Navigation/Navigation-Data-and-Information/US-Port-Statistics/).
