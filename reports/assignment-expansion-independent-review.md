# Independent assignment expansion review

**Scope.** The review exercised the bounded single-addition expansion contract on small synthetic geographic scenes. The scenes were generated from catalog records and angular measurements, and each seed came from the canonical scorer. No truth input, accepted fix, held-out input, large diagnostic, or GPU run was used.

**Implementation reviewed.** The expansion tests ran against source commit `6d4a57d` on `accuracy/assignment-expansion`, including the prepared-seed geometry cache. The companion runner was read at commit `4f67bc5` on `accuracy/assignment-expansion-runner`. The runner consumes exactly 64 completed assigned-refinement rows, revalidates both saved starts, selects the deterministic lower-score start with label tie breaking, keeps the canonical lock, checks the 40 GiB reserve and 20 MiB output cap around every branch event, records resource and branch failures, and writes `full_domain_complete=false` with `certificate_scope=none`. The preflight report records 22,000 candidate branches across the 64 modes without executing them.

**Adversarial coverage.** The nine focused tests cover stale score or assignment rejection, explicit covariance rejection, callback ordering and exception propagation, exact branch-budget accounting, stable catalog-key ordering across catalog permutations, one-to-one and angular-group duplicate handling, clipped local bounds and the `max_nfev` limit, canonical assignment retention when a proposed key is not retained, and independent verification that residuals use WGS84 true-north bearings with report-specific sigma and catalog uncertainty combined in quadrature.

**Verification.** The focused suite passed with `9 passed in 0.42s` against `6d4a57d`. Ruff checks and formatting passed for the review test module. The suite was run from `/tmp` with `PYTHONPATH` pointing to the owner source and review worktrees so the test did not accidentally import an incomplete local package. No implementation defect was reproduced by these tests. The runner’s existing focused suite was not rerun from this review worktree because its source and test files belong to the runner owner; the owner reported its 34 focused tests passing at `4f67bc5`.

**Disposition.** The expansion implementation is ready for coordinator integration from the reviewed source state. The production diagnostic remains an explicitly incomplete heuristic run. Its execution should preserve the recorded source and input hashes, the 64-mode artifact, the branch counters, and every failure or resource outcome in the durable output.
