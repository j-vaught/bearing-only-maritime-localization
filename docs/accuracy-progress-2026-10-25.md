An isolated candidate-independent setup loop had a median of 478.8 ms, approximately 98% of the candidate-call median. This is directional overlap from an isolated diagnostic, not a controlled benchmark or a precise stage timing.

The progress update did not include an exact refresh time. The source data JSON records that limitation and the figure compilation timestamp of 2026-10-25 23:50 EDT.
