# Full-coast search diagnostic figure

This figure compares three failed search runs for the same frozen five-observation development case. It separates the score-ranked estimate error from the minimum error among saved hypotheses, since those values describe different candidates. It also displays each run's external wall time as a separate diagnostic observation and marks the timing scopes rather than presenting them as a controlled speed comparison.

The pairwise result uses the A35 CRS correction. Evaluator truth is recorded in EPSG:32619 while search estimates use EPSG:32618; A35 transformed the truth before recomputing geodesic distances. The corrected pairwise top error is 509,653.742 m and the minimum among seven saved hypotheses is 506,055.789 m. The planar wedge retained 260 hypotheses, with a 1,898,447.237 m top-ranked error and a 1,897.057 m minimum saved error. The geodesic wedge retained 261, with a 548,327.465 m top-ranked error and a 128,757.746 m minimum saved error. None of these searches accepted a position.

Both wedge runs processed all 333,340 configured source pairs. The planar run emitted 1,530,303 cells. The geodesic run emitted 1,457,546 cells but recorded 209 failed geodesic samples among 83,001,660, so generation completeness was false even though it visited every source pair. Each run used a 256-candidate scoring cap. The pairwise run used a 64-candidate cap; its report records 54 generated and evaluated candidates, four retained candidates, and 50 invalid-water outcomes.

The lower objective at evaluator truth, 5.206587, is post-search evidence. The exact audit found that the 250 m cell containing truth was generated and classified as water, but it was omitted from the exact-scored top-256 set. Its mean normalized residual, 0.23667468, exceeded the last selected proposal's 0.02674343. The containing cell scored 17.849167, its neighboring water cell scored 16.355641, and the returned top candidate scored 23.786193. Therefore, an explanation based only on the angle window does not account for this miss: the cell existed in generated proposals and was skipped by residual-based ordering under the candidate cap. The truth position and truth-derived identities were accessed only by evaluator code after the search outputs were written.

The adjacent JSON preserves the relevant report and artifact hashes, search input hashes, the frozen search commit, and all plotted values. Primary sources are the A43 report, the A26 planar wedge report, the A26 geodesic report and telemetry package at commit e940dad, and the A35 evaluator audit. The figure does not establish accepted localization accuracy, held-out performance, field validation, or a general runtime comparison.

Typst generated the figure PDF and PNG. The PDF and rendered page were inspected after compilation; checks verified the JSON source, plotted values and units, provenance references, and scope labels. No search, scoring, or model code was run or changed for figure production.


The 209 failed geodesic samples are recorded as the frozen-run outcome. A separate solver audit after that run found all 209 converged when the internal iteration target was tightened to half the public tolerance. That audit did not change the frozen estimate, telemetry, or failed status; the figure reports the run as executed and notes the later correction to avoid implying those failures remain unresolved in the current solver.
