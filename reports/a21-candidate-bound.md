# Candidate-level objective lower bound

## Scope

This bound applies to one candidate observer position and the `bearing_set_map_v1` objective. Its only visibility input is a certified minimum $K$ on the number of distinct predicted visible groups. It makes no region, coast, or geometric certificate claim. A visibility scan may stop early when its certificate still proves $K$; an incomplete scan with a valid certificate is supported. The caller passes minimum_visible_group_count and certified from the visibility result; visibility_count_certified defaults to false. An unresolved, omitted, or uncertified count produces no bound.

The bound also requires the configured variance model to be supported. Diagonal per-report covariance and the configured finite generated-sigma fallback use the canonical likelihood implementation. Non-diagonal covariance, common-bearing-bias integration, an unsupported variance model, and any objective version other than `bearing_set_map_v1` return a structured unresolved result.

## Prepared-request API

The preparation function computes the canonical baseline, clutter cost, group-miss cost, and global report match floors once. Its frozen result contains only scalar values, tuples, and the immutable SearchConfig; it retains no aliases to caller-owned arrays or metadata. Call the prepared result's bound method for each candidate K. The existing one-shot function delegates through this API, and the cardinality formula and numerical margin remain the same. Both visibility certification and variance-support default to false and must be explicitly enabled by the caller; they must be actual booleans, and other values return unresolved.

## Objective and derivation

Let $m$ be the number of reports, $n$ the actual number of predicted visible groups, and $k$ the number of matched report/group pairs in a partial injective assignment $A$. The complete score is

$$
C(A)=\Lambda+(m-k)r+(n-k)g+\sum_{(i,j)\in A}c_{ij},
$$

where $\Lambda$ is the objective baseline, $r=-\log(\lambda/360)$ is the exact report-clutter cost in degree-based bearing density units, $g=-\log(1-P_D)$ is the cost for each unused group, and $c_{ij}$ is the canonical matched negative log likelihood. The certificate establishes only $n\geq K$.

For report $i$, its report sigma $\sigma_i$ is supplied or generated by the configured objective. Every supported predicted-group uncertainty is nonnegative, so the smallest combined sigma is $\sigma_{i,\min}=\max(\sigma_i,\sigma_{\mathrm{floor}})$, attained by zero predicted uncertainty. The wrapped Gaussian plus uniform outlier density has its maximum at zero residual. Since every valid hard or soft type factor satisfies $q_{ij}\leq1$, each matched cost obeys

$$
c_{ij}=-\log(P_D f_{ij}q_{ij})\geq
c_i^*=-\log(P_D f_{\max}(\sigma_{i,\min})).
$$

The implementation obtains $c_i^*$ by calling the canonical likelihood builder at zero residual with type weighting disabled and predicted uncertainty set to zero. This uses the same wrapped-density calculation, outlier probability, detection probability, degree units, and sigma floor as final scoring. It does not replace or approximate the score function.

For a fixed match cardinality $k$, the fewest unmatched groups possible under $n\geq K$ is $\max(K-k,0)$. The bound allows $k$ to exceed $K$, because unexamined objects may add groups. It relaxes one-to-one matching by letting the $k$ reports use their globally best edge floors, selected as the $k$ smallest values among $c_i^*$. The resulting cardinality lower bound is

$$
L_k=\Lambda+(m-k)r+\max(K-k,0)g+\sum_{i=1}^{k}c_{(i)}^*,
\qquad k=0,\ldots,m,
$$

where $c_{(i)}^*$ are the report floors sorted in ascending order. The reported bound is $L=\min_k L_k$. For any actual candidate assignment, its group count is at least $K$, its matched edges are no cheaper than their report floors, and its unmatched report/group counts are no smaller than the terms used in $L_k$. Therefore $L$ cannot exceed the complete objective.

When $\lambda=0$, the report-clutter cost is positive infinity. The implementation treats the zero-unmatched-report cardinality separately so it never evaluates $0\cdot\infty$. This preserves the objective's requirement that every report must match for a finite score. Negative finite matched NLL values are kept in the sorted floors and cardinality sums.

## Numerical margin and pruning

The score is reduced by a default $10^{-10}$ margin scaled by one plus the absolute baseline, all finite report-clutter contributions, the $K$ group-miss contribution, and the absolute report floors. The implementation then applies one downward `nextafter` step. The pruning helper returns true only when a supported bound is strictly greater than a feasible incumbent score plus the caller's comparison margin. Unsupported results and ties continue evaluation.

With the configured defaults, $P_D=0.9$, $\sigma_{\mathrm{floor}}=0.05^\circ$, and $\lambda=1$. Thus $g=\log 10$, $r=\log 360$, and $\Lambda=1$. These values are read from the active configuration rather than hard-coded into the bound.

## Limits

The result is valid only for the fixed-candidate objective and a valid lower-bound certificate on visible group count. It does not establish the exact number of groups, their bearings, their representatives, or any spatial-region objective bound. A group-count certificate may be conservative because pre-line-of-sight components can include occluded members; its value is useful only when the visibility-screen implementation proves that each counted component contributes a distinct visible group. Unknown variance or model behavior cannot be replaced by a guessed sigma or type factor.
